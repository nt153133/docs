FFXIV's UI is built from named ATK addon windows. LlamaLibrary wraps over 100 of these windows in typed C# classes so you can read their state and trigger button clicks or selections without writing raw memory or UI action code yourself. Every window class follows the same pattern: a static `Instance` singleton, an `IsOpen` property, and methods that correspond to the interactions you would perform in the game UI.

## Base class

Every window in LlamaLibrary inherits from the generic `RemoteWindow<T>` base class, which itself inherits from the abstract `RemoteWindow` class. Understanding what the base class provides helps you work with any window in the namespace.

```csharp
// The base class generic variant — all window classes follow this pattern
public class RemoteWindow<T> : RemoteWindow
    where T : RemoteWindow<T>, new()
{
    public static T Instance { get; } // singleton accessor
}

public abstract class RemoteWindow
{
    public virtual bool IsOpen { get; }         // true when the window is visible in the game UI
    public virtual string WindowName { get; }   // the internal ATK window name
    public virtual AgentInterface Agent { get; } // the associated UI agent, if any

    public virtual void Close();                // sends the close action to the window
    public async Task<bool> WaitTillWindowOpen(int maxTimeOut = 5000); // polls until open
    public virtual async Task<bool> Open();     // toggles the agent to open the window
    public void SendAction(int pairCount, params ulong[] param); // sends a raw UI action
}
```

`WaitTillWindowOpen` is particularly useful in coroutine-based automation: call it after triggering an NPC interaction or menu selection to pause until the window is ready before reading its contents or clicking buttons.

<Note>
  Window state is read directly from the game's UI layer. A window reports `IsOpen` as `true` only when it is actually rendered in the client. If the game client lags or a network action is pending, `IsOpen` may be `false` even after you triggered the open. Always use `WaitTillWindowOpen` rather than checking `IsOpen` immediately after an action.
</Note>

<AccordionGroup>
  <Accordion title="Retainers">
    These windows are used during retainer bell interactions.

    | Class | ATK name | Description |
    |-------|----------|-------------|
    | `RetainerList` | `RetainerList` | The retainer selection list shown after touching a summoning bell. Exposes `OrderedRetainerList`, `NumberOfRetainers`, `NumberOfVentures`, per-retainer name/level/job, and `SelectRetainer(int index)` / `SelectRetainer(ulong contentId)`. |
    | `RetainerHistory` | `RetainerHistory` | Shows the history of a retainer's completed ventures. |
    | `RetainerTaskList` | `RetainerTaskList` | The venture task selection list for a retainer. |
    | `InventoryBuddy` | `InventoryBuddy` | The chocobo saddlebag window. |

    **RetainerList usage example**

    ```csharp
    using LlamaLibrary.RemoteWindows;

    // Wait for the list to appear after interacting with a bell
    if (!await RetainerList.Instance.WaitTillWindowOpen(10000))
    {
        Log.Error("RetainerList did not open in time.");
        return;
    }

    Log.Information($"Found {RetainerList.Instance.NumberOfRetainers} retainers.");
    Log.Information($"Ventures remaining: {RetainerList.Instance.NumberOfVentures}");

    // Select the first retainer by index
    await RetainerList.Instance.SelectRetainer(0);
    ```

  <Accordion title="Crafting & Gathering">
    Windows that appear during crafting turn-ins, collectables, and gathering spiritbond interactions.

    | Class | ATK name | Description |
    |-------|----------|-------------|
    | `MasterPieceSupply` | `MasterPieceSupply` | The Rowena collectables hand-in window. |
    | `CollectablesShop` | `CollectablesShop` | The collectables shop turn-in window. Exposes `RowCount`, `TurninCount`, `SelectJob(int job)`, `SelectItem(int line)`, `Trade()`, `GetItems()`, and `ListItems()`. |
    | `GatheringMasterpieceLL` | `GatheringMasterpiece` | Spiritbond and masterpiece gathering window wrapper. |
    | `SatisfactionSupply` | `SatisfactionSupply` | The Custom Deliveries (satisfaction supply) turn-in window. |
    | `SatisfactionSupplyResult` | `SatisfactionSupplyResult` | The result window shown after a Custom Deliveries turn-in. |

    **CollectablesShop usage example**

    ```csharp
    using LlamaLibrary.RemoteWindows;

    if (CollectablesShop.Instance.IsOpen)
    {
        // Switch to the correct crafting job tab
        CollectablesShop.Instance.SelectJob(0);

        // Get all available turn-in items
        var items = CollectablesShop.Instance.GetItems();
        foreach (var (itemId, line) in items)
        {
            Log.Information($"Available: item {itemId} at line {line}");
        }

        // Select and trade the first item
        CollectablesShop.Instance.SelectItem(0);
        CollectablesShop.Instance.Trade();
    }
    ```

## General usage pattern

Every window follows the same access pattern. Check `IsOpen` before reading data, use `WaitTillWindowOpen` after triggering an action, and call `Close()` when you are done.

```csharp
using LlamaLibrary.RemoteWindows;

// Check if a window is currently open
if (RetainerList.Instance.IsOpen)
{
    // Read data or send actions
    int count = RetainerList.Instance.NumberOfRetainers;
}

// Wait for a window to open after triggering an action (e.g. NPC interaction)
if (!await CollectablesShop.Instance.WaitTillWindowOpen(8000))
{
    Log.Error("CollectablesShop did not open.");
    return;
}

// Close a window when done
GrandCompanySupplyList.Instance.Close();
```
