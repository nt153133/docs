LlamaLibrary is actively maintained and updated alongside Final Fantasy XIV patches and RebornBuddy releases. Because LlamaLibrary reads game memory directly, it must be updated whenever the game changes the internal structures it depends on. Staying current is not optional — an outdated installation can cause crashes, broken behavior, or silent failures in any botbase or plugin that depends on the library.

## Week of June 1, 2026

### New features

- **Tiisol Ja custom delivery support.** The new Tuliyollal custom delivery client (unlocked via quest 70996) is now a first-class target in the custom delivery helpers. `RunCustomDeliveriesBySelection` accepts a new `doTiisolJa` toggle, the NPC and required quest are registered in the custom delivery resource list, and the Tiisol Ja vendor and five new turn-in item mappings are wired into the gil-shopping helper so crafted hand-ins resolve to the correct vendor automatically. See the [retainer and custom delivery guide](/guides/retainer-automation) for usage.
- **FFXIV 7.51 support.** Game version numbers and the `GetUiModule` offset pattern have been updated for FFXIV patch 7.51. Any helper that touches the UI module — most remote windows, agents, and UI-driven automation — now resolves correctly on the patched client.

### Updates

- **More reliable offset verification.** The offset system now supports per-offset ambiguity overrides, so patterns that legitimately match more than one location no longer fail verification at startup. Expect fewer false-positive offset errors after FFXIV patches that introduce duplicated code regions.
- **Expanded IntelliSense coverage.** Another wave of XML documentation landed across the public API, including `Navigation`, the retainer classes, `ItemFinder` and related inventory types, `CollectablesShop`, `Conversation`, `RaceChocoboManager`, `RelicBookManager`, `LocalPlayerExtensions`, `UIState`, `UIInputHelper`, `SnipeManager`, `LibraryClass`, and `AssemblyProxy`. If you write botbases or plugins against LlamaLibrary, your IDE should now surface meaningful tooltips and parameter hints for nearly every commonly used type. The [helpers overview](/reference/helpers-overview), [navigation and travel guide](/guides/navigation-travel), and [extensions reference](/reference/extensions) reflect the same information.

## Week of May 25, 2026

### New features

- **The Finer Miner mini-game support.** A new `MiniGameMiner` remote window lets botbases and plugins drive the Gold Saucer mining mini-game the same way they drive Out on a Limb — pause and resume the oscillating cursor, and trigger the swing button. See the [remote window reference](/reference/remote-windows) for usage.
- **Difficulty selection for Gold Saucer mini-games.** `MiniGameAimg` now exposes a `SetDifficulty` method with named values (`Cactuar`, `Morbol`, `Titan`), replacing the previous untyped button press. The old `PressButton` call is still available but marked obsolete.
- **`OutOnALimbDirector` now covers The Finer Miner.** The director reads swing results and round state for both Out on a Limb and The Finer Miner, and `MaxNumberOfSwings` now reads the per-round limit dynamically (10 for Out on a Limb; 4–6 for The Finer Miner depending on difficulty) instead of returning a fixed value.

### Updates

- **Better IntelliSense across the public API.** XML documentation was added to a large set of core types — including `LocalPlayer` extensions, retainer automation classes, `OrderbotHook`, `SnipeManager`, `BagSlot` extensions, core interfaces, and the main library entry points. If you write botbases or plugins against LlamaLibrary, you should now see meaningful tooltips and parameter hints in your IDE without diving into the source. The [helpers overview](/reference/helpers-overview) and [extensions reference](/reference/extensions) reflect the same information.

### Bug fixes

- **`OutOnALimbDirector.SwingResult` no longer misreports an idle round.** A swing result byte of `0` (no swing taken yet) is now handled explicitly and returns a zero result instead of falling through to the `TryAgain` default. Mini-game scripts that polled the director between swings should no longer see spurious `TryAgain` events.

## Staying up to date

You have two options for keeping LlamaLibrary current:

**updateBuddy (recommended)**

Install the [updateBuddy](https://loader.updatebuddy.net/UpdateBuddy.zip) plugin into your `Plugins\updateBuddy` folder. Each time RebornBuddy starts, updateBuddy checks the LlamaLibrary GitHub repository for new commits and applies any updates automatically. You do not need to monitor releases or pull changes manually.

**Manual updates**

If you prefer not to use updateBuddy, you can update LlamaLibrary yourself:

1. Download or pull the latest from [https://github.com/nt153133/__LlamaLibrary](https://github.com/nt153133/__LlamaLibrary).
2. Replace the contents of your `QuestBehaviors\__LlamaLibrary` folder with the new files.
3. Restart RebornBuddy.

This approach requires you to check for updates yourself, particularly after every FFXIV patch.

## Why updates matter

FFXIV patches routinely change game memory layouts, internal function signatures, and UI structures. LlamaLibrary's offset system reads these memory locations directly to expose game data and trigger game actions. When a patch ships, previously valid offsets may point to wrong locations or no longer exist at all.

Running an outdated version of LlamaLibrary after a game patch can cause:

- RebornBuddy crashes on startup during offset initialization
- Incorrect or missing data returned from game memory reads
- Broken interactions with game UI windows and agents
- Navigation and retainer automation failures

Updating LlamaLibrary immediately after a FFXIV patch is the single most effective step you can take to prevent these problems.

<Warning>
  Always update LlamaLibrary immediately after every FFXIV patch and before reporting any bug. Many issues that appear to be botbase bugs are caused by stale offsets in an outdated LlamaLibrary installation. Running the latest version rules out the most common cause of breakage.
</Warning>

## What changes between versions

Updates to LlamaLibrary fall into several recurring categories:

**Offset updates after FFXIV patches**
The most common type of update. When a game patch changes internal memory structures, offsets throughout LlamaLibrary are recalibrated to match the new layout.

**New remote window wrappers**
When FFXIV adds or changes game UI windows and agents, LlamaLibrary adds or updates the corresponding remote window and agent wrapper classes so botbases can interact with them.

**New helper functions for game content**
As new game content ships — new duties, crafting recipes, retainer ventures, Grand Company items — LlamaLibrary gains helper functions and resource data to support automation of that content.

**Bug fixes for retainer, navigation, and crafting helpers**
Targeted fixes for specific failure modes in the retainer automation, navigation provider integration, and crafting helper subsystems.

**New template class features**
Improvements to `TemplateBotBase`, `TemplatePlugin`, and related scaffolding — such as new lifecycle hooks, updated logging behavior, or convenience properties.
