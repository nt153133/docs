LlamaLibrary is a comprehensive C# support library for [RebornBuddy](https://www.rebornbuddy.com/) developers creating botbases, plugins, and quest behaviors for Final Fantasy XIV. It exposes helper functions, template base classes, remote window wrappers, retainer automation, navigation utilities, and shared game data that RebornBuddy does not provide out of the box.

## Get started in three steps

<Steps>
  <Step title="Install LlamaLibrary">
    Use the updateBuddy plugin for automatic installation and updates, or clone the repository manually into `RebornBuddy\QuestBehaviors\__LlamaLibrary`. See [Installation](/installation) for full details.
  </Step>
  <Step title="Reference the NuGet package">
    Add the `LlamaLibrary` NuGet package to your Visual Studio project for compile-time IDE support and IntelliSense while you develop.
  </Step>
  <Step title="Extend a template class">
    Subclass `TemplateBotBase` or `TemplatePlugin`, override the required members, and start calling LlamaLibrary helpers from your `Run()` method. See [Quick Start](/quickstart).
  </Step>
</Steps>
